# Шпаргалка по типографским единицам измерения (Typst vs Word)

Эта шпаргалка объясняет, как соотносятся единицы измерения при генерации PDF (Typst) и DOCX (`docx-rs`) в нашем генераторе документов.

## 1. Базовые единицы (Typst / PDF)

* **Пункт (pt):** Фундамент типографики. Абсолютная физическая величина (1/72 дюйма). Используется для задания базового размера шрифта (например, `12pt` или `14pt`).
* **em:** Относительная величина, которая всегда равна *текущему размеру шрифта*.
    * Если базовый текст задан как `12pt`, то `1em = 12pt`.
    * *Пример:* Отступ красной строки `1.5em` при 12-м шрифте физически равен `1.5 * 12 = 18pt`.

## 2. Единицы Microsoft Word (`docx-rs`)

Формат Word (OpenXML) принципиально не использует целые пункты, дробя их для максимальной точности при печати.

### Полупункты (half-points)
Используются **только для указания размера текста**.
* **Правило:** 1 пункт = 2 полупункта.
* **Формула:** `Желаемый размер (pt) * 2`.
* **Примеры в коде:**
    * Шрифт `12pt` записывается как `.default_size(24)`
    * Шрифт `14pt` записывается как `.default_size(28)`

### Твипы (twips)
От английского *twentieth of a point* (1/20 пункта). Это главная мера длины в Word для всего остального: отступов, ширины колонок таблиц, полей страницы и межстрочных интервалов.
* **Связь с пунктами:** 1 пункт = 20 твипов.
* **Связь с сантиметрами:** 1 см ≈ 567 твипов.

## 3. Практические примеры и конвертация

Чтобы точно перенести отступ `1.5em` (при шрифте `12pt`) из шаблона Typst в DOCX, проходим цепочку:
1. Переводим `em` в пункты: `1.5em * 12pt = 18pt`.
