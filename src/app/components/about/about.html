info О программе File Flow Высокопроизводительный десктопный файловый менеджер

О проекте

File Flow — это современная десктопная утилита, созданная для глубокого анализа файловой системы, поиска дубликатов и наведения идеального порядка на диске.

Технологический стек

terminal
Ядро (Бэкенд): Rust
Многопоточный поиск, высокая производительность
 web
Интерфейс: Angular + Angular Material
Современный адаптивный UI
 desktop_windows
Платформа: Tauri
Легковесная нативная оболочка
